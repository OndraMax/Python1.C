# Generátor hesel

# Popis a cíl projektu
Procvičit práci s textem a náhodný výběr znaků.

# O co jde?
Uživatel zadá délku a program vypíše náhodné heslo z malých, velkých písmen
a číslic.

# Technická část
Soubor `generatorhesel.py` používá random a string. String poskytuje písmena
a číslice, random.choice vybírá náhodné znaky. Cyklus for přidává znaky
do hesla podle zadané délky.

# Kontrola funkčnosti
Zadat délku 8 a potom 12. Výsledek má mít zadaný počet znaků a obsahovat
pouze písmena a číslice.
