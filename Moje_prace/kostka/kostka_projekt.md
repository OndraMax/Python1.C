# Hrací kostka

# Popis a cíl projektu

Procvičit náhodná čísla, cykly a sčítání hodů kostkou.

# O co jde?

Uživatel zadá počet hodů od 1 do 100. Program vypíše jednotlivé hody šestistěnnou kostkou a jejich součet. Pokud zadá text nebo číslo mimo rozsah, program se zeptá znovu.

# Technická část

Soubor `hracikostka.py` používá random.randint pro náhodný hod. Cyklus while a try/except kontrolují vstup. Cyklus for opakuje hody a přičítá je do proměnné celkem.

# Kontrola funkčnosti

Zadat text, 0 a 101 a ověřit, že je program odmítne. Potom zadat 3. Mají se vypsat tři hody od 1 do 6 a jejich správný součet.
